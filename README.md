# Sessiz Bağıran Asansör Protokolü

> Resmiyet derecesi: **zirve toplantısı**.  
> Fayda derecesi: **bilimsel olarak ölçülemez**.  
> Gürültü derecesi: **fısıltının altı**.

Bu depo, bir asansör düğmesine yanlış basıldığında evrenin ruhundan özür dilemek için yazılmış uluslararası bir protokoldür. Kod çalışır. Vicdan da çalışır. Asansör bazen çalışmaz.

## Neden var?

Çünkü yanlış kata basmak sadece bir hata değildir.  
Bu, kâinatın kat planına karşı işlenmiş idari bir suçtur.  
Bu yazılım o suçu **sessizce bağırarak** itiraf eder.

## Kurulum

```bash
git clone https://github.com/Tentivory/sessiz-bagiran-asansor-protokolu.git
cd sessiz-bagiran-asansor-protokolu
python3 asansor.py 7 12
```

İlk sayı gitmek istediğin kat, ikinci sayı parmağının ihanet ettiği kat.

Argüman vermezsen protokol kendi kendine rastgele bir utanca karar verir.

## Örnek çıktı

```
=== SESSİZ BAĞIRAN ASANSÖR PROTOKOLÜ ===
Hedef kat     : 7
Basılan düğme : 12
Sayın Evren, 12. kata yanlışlıkla temas edilmiştir. Özürlerimizin kabulünü rica ederiz.
```

## Mimari

- Python 3
- Rastgele özür motoru
- Daktilo efekti (çünkü evren acele etmez)
- Resmi damga (hem ciddi hem değil)
